    Personal project

    AI Car Advisor

    A conversational car advisor built as a four-project .NET monorepo: a REST API, an HTTP MCP server, a Blazor UI and a Microsoft Agent Framework agent. The model reaches data only through MCP tools, and only the API touches the database.

    MCP resources and prompts load from JSON manifests, so adding one needs no C# change. The database layer uses an adapter pattern for SQLite and SQL Server. Authentication work covers OAuth 2.1 with PKCE, JWT validation and Microsoft Entra ID.

    ORION

    An autonomous incident investigation system. Agents form and test hypotheses about a production incident using evidence gathered through MCP tools, then work toward a remediation. It follows the same evidence-first approach as my other MCP work, applied to site reliability.
